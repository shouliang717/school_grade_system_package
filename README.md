# 小型學校月段考成績管理、學習進步追蹤與補考採計系統 (伺服器部署版)

本專案為純前端靜態網頁系統（HTML5 + Tailwind CSS + Chart.js），可直接部署於任何學校網頁伺服器（Apache、Nginx、IIS）或靜態網站空間（GitHub Pages、Vercel、Netlify、校園內部虛擬主機）。

---

## 📁 壓縮包目錄結構

```text
school_grade_system_package/
├── index.html                           # 模組化主入口網頁 (適合放置於網站根目錄)
├── css/
│   └── styles.css                       # 系統排版與 A4 公務列印樣式表
├── js/
│   └── app.js                           # 核心計分、補考折算、進步排行与圖表引擎
├── school_grade_system_standalone.html  # 單一檔案完整封裝版 (可離線雙擊開啟或單檔部署)
├── samples/                             # 班級批次匯入標準範例檔
│   ├── 班級學生名冊與雙次段考匯入範例檔.csv   # Excel 相容 UTF-8 (含 BOM) 範例
│   └── 班級學生名冊與雙次段考匯入範例檔.txt   # 純文字 Tab 分隔範例
└── README.md                            # 伺服器架設與功能說明文件
```

---

## 🚀 伺服器部署方式

1. **標準伺服器部署（Apache / Nginx / IIS / 學校校網主機）**：
   - 將 `index.html`、`css/`、`js/` 與 `samples/` 解壓縮後直接上傳至伺服器之網站公開目錄（例如 `/var/www/html/grades/` 或 `public_html/`）即可透過網址立即瀏覽使用。
2. **單一檔案快速嵌入或離線使用**：
   - 若僅需單一網頁檔，可直接上傳或開啟 `school_grade_system_standalone.html`，內含所有樣式與腳本，無外部本地路徑相依性。

## ✨ 系統核心功能總覽

1. **雙次段考獨立登打與分流導師評語**
   - 支援「第一次段考」與「第二次段考」獨立成績登打與獨立導師評語（`notes1`、`notes2`），以及「兩次段考綜合比較分析」（`specialNotes`）。
   - 單次段考報表（一段成績冊、二段成績冊、一段個人通知單、二段個人通知單）僅呈現該次段考專屬評語；兩次段考合併對比報表則一併並列呈現一段評語、二段評語與綜合比較分析。
2. **五科未滿 60 分補考名冊與法定折算採計**
   - 內建「國文、英語、數學、自然、社會、五科總覽」切換選單，自動篩選未滿 60 分之一般受測生。
   - 嚴格遵循教育部評量準則：補考超過 60 分以 **60 分** 採計；未達 60 分則與原成績比較取**低於 60 分之最高分**採計，並於所有報表自動標註 `(補)` 與折算說明。
3. **兩次段考對比、進步獎排行與五標級距消長**
   - 自動計算個人總平均差值、成長率（%）、名次升降、各科進步排行榜，並提供個人五角能力雷達診斷卡與兩次段考五級距人數消長對照圖。
4. **特殊生（特教/資源/扶助）彈性評量與五聯行政核章列印**
   - 支援特教考場調整註記與「IEP 免列常態排名」保護。
   - 內建八種公務列印格式，統一配置「班級導師、教務組長、特教/輔導業務、教導主任、校長核示」五聯核章與公開張貼隱私保護開關。
